What it is

An app for a phone whose physical buttons have stopped working. It puts the volume, the screen lock and the power menu on the screen, and in the notification shade, so the phone stays usable after the hardware does not.

What it does

  • Volume. Volume up, volume down and mute, plus a separate slider for each stream: Media, Ring, Notification, Alarm and Call.
  • Lock the screen. Using Android's Device Administrator, the same mechanism a system lock button uses.
  • Open the power menu. Using a deliberately minimal Accessibility service, so you can still reach power off and restart.
  • Keep the screen on while the app is open, for a phone whose screen timeout is a nuisance without working buttons.
  • Notification controls. An ongoing notification with volume, lock and power actions, so the phone can be controlled from the shade without opening the app at all.

What it asks for, and why

This is not a zero-permission app, and it does not pretend to be. Each of these exists to do one visible job:

Device Administrator
Only for locking the screen. It is not used to erase the device, change passwords or read anything.
Accessibility service
Only for opening the system power menu. It is declared with canRetrieveWindowContent="false" and requests no event types at all, which means it cannot read what is on your screen. Some apps use an Accessibility service to see everything you do; this one is written so that it cannot.
Foreground service
Keeps the notification control panel alive so the controls are always one swipe away.
Notifications
The control panel itself. On Android 13 and newer, Android asks you to allow notifications when the app first needs them.
Boot completed
Restores the control panel after the phone restarts.
Modify audio settings
Changes the volume streams described above.
Vibrate
Optional haptic feedback, off unless you switch it on.

Soft Keys does not hold the internet permission. There is no way for it to send anything anywhere, which is also why it has no analytics, no crash reporting and no ads.

Privacy

Nothing is collected. Preferences, such as whether haptic feedback is switched on, are ordinary local settings on your device. Full details are in the plain.view privacy policy, which states the same permissions and data collection for this app.

Requirements

  • Android 8.0 (API level 26) or newer
  • No root. No OTG adapter. No account.
