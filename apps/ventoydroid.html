What it is

VentoyDroid brings Ventoy to Android. Plug a USB stick into your phone with an OTG adapter, install the Ventoy bootloader, copy ISO files onto the stick, and boot any PC from it. No computer is needed, and there is no root.

What it does

  • Installs the real Ventoy bootloader. The version 1.0.99 payload is bundled with the app and verified by SHA-256 before use. The GRUB boot code, the core image and the VTOYEFI partition are written exactly where the official installer puts them.
  • Formats the data partition as FAT32 or exFAT, using filesystem drivers that run inside the app. exFAT is chosen automatically when any ISO is 4 GiB or larger, which is what Windows 11 and large Linux images need; FAT32 is used otherwise, for the widest compatibility. Either way the stick appears on any computer as an ordinary drive.
  • Copies ISO files from your phone onto the stick, streamed so that even a multi-gigabyte file never sits in memory, then verifies that every file landed intact.
  • Manages an installed stick. List, add and remove ISOs later without reinstalling Ventoy. You can also just copy more ISOs onto the stick from any computer.

The stick it produces is a standard Ventoy stick, fully compatible with the official Windows, Linux and Mac installer.

How it works without root

Android apps cannot write to mounted USB storage. They can, however, claim a USB device through the Android USB Host API and speak its protocol directly. VentoyDroid issues SCSI commands (READ(10) and WRITE(10)) over USB Bulk-Only Transport, bypassing the system's storage layer entirely. The partition-table writer, the filesystem driver and the installer logic all run inside the app.

What it asks for, and why

USB host access
Access to the stick you plug in, granted by you for that one device. It is what lets the app write the bootloader without needing any permission to read your phone's storage.
Internet, network state
For the Google advertising described below, and for nothing else.
Foreground service, wake lock
Keeps a long install from being killed part-way, and stops the phone sleeping mid-write, which is the one moment an interruption could damage the stick.
Notifications
The progress of an install, with a button to cancel it.
Advertising ID and ad-services permissions
Added by Google's AdMob library rather than written by hand: com.google.android.gms.permission.AD_ID and the ACCESS_ADSERVICES_AD_ID, ACCESS_ADSERVICES_ATTRIBUTION and ACCESS_ADSERVICES_TOPICS permissions.

VentoyDroid does not request permission to read your phone's storage, and it writes only to the stick you select and confirm.

Advertising, and what it means for you

VentoyDroid is ad-supported. It shows a banner supplied by Google AdMob, and one full-screen advertisement after an install finishes. Because Google serves those advertisements, Google collects the data its own policies describe, which can include device identifiers, IP address, ad interaction and approximate location. plain.view never receives any of it. Where the law requires it — in the EEA, the UK and Switzerland — Google's consent form appears first, and declining it leaves the app fully usable, just without ads.

This is the one app published by plain.view that uses the network at all, and the privacy policy says so in the same words used here. It is stated on this page, in the policy and in the store listing because it is the one thing about this app a person should know before installing it.

Files and privacy

Your ISO files never leave your phone. They are streamed straight from your storage to the USB stick, and the app has no server of its own to upload them to. Nothing is uploaded automatically: if you tap Report this problem, your own mail app opens with a technical report already written, and nothing is sent until you press send there. You can read and edit it first, or not send it.

Requirements and limitations

  • Android 8.0 or newer, on a phone that supports USB host (OTG)
  • An OTG adapter, or a phone with a built-in USB port
  • A USB stick of about 2 GiB or more. Everything already on the stick will be erased, and the app asks you to confirm that before it writes anything.
  • MBR partition layout only, which matches the official default. GPT is not supported yet.
  • There is no non-destructive install and no update mode yet.
  • The install pipeline is tested end to end against a virtual disk, but how a stick boots still varies with PC firmware. Test your stick on the machine you intend to use it with.
